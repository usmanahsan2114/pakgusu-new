# Resources Main Page Design Documentation

**URL:** `/resources/`
**Source File:** `intoriza/resources/index.html`
**Parent Template:** N/A

## Page Overview
Central hub for educational and informational content including blog, news, FAQs, and cleanroom standards.

## Section-by-Section Design

### 1. Header
- **Type:** Standard Global Header
- **Includes:** Dark Mode Toggle. Header is always Dark Blue (#004685) with Light Blue (#29afe3) accents. See [Dark Mode](../dark-mode.md).

### 2. Page Title / Breadcrumb
- **Type:** Inner Page Banner
- **Content:** "Resources" title and breadcrumb.

### 3. Resource Categories Grid
- **Layout:** 2x2 or 4-Column Grid.
- **Content:**
    - Cleanroom Standards & Classifications
    - Blog
    - News & Events
    - FAQs
- **Styling:** Icon boxes or image cards linking to sub-pages.

### 4. Featured Content (Optional)
- **Layout:** 3-Column Grid.
- **Content:** Latest blog posts or news highlights.

### 5. Footer
- **Type:** Standard Global Footer (Dark Blue #004685, Light Blue #29afe3 accents, white text)
