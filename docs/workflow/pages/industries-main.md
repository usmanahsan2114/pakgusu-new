# Industries Main Page Design Documentation

**URL:** `/industries/`
**Source File:** `intoriza/industries/index.html`
**Parent Template:** `index-3.html`

## Page Overview
Overview of the industries and sectors served by PakGusu's cleanroom solutions, linking to detailed pages for each industry.

## Section-by-Section Design

### 1. Header
- **Type:** Standard Global Header
- **Includes:** Dark Mode Toggle. Header is always Dark Blue (#004685) with Light Blue (#29afe3) accents. See [Dark Mode](../dark-mode.md).

### 2. Page Title / Breadcrumb
- **Type:** Inner Page Banner
- **Content:** "Industries We Serve" title and breadcrumb.

### 3. Industries Overview Text
- **Layout:** Centered text block.
- **Content:** "Our cleanroom solutions are trusted across multiple sectors requiring contamination control."

### 4. Industries Grid / Carousel
- **Layout:** 3-Column Grid or Owl Carousel.
- **Content:**
    - Pharmaceutical & Nutraceutical
    - Healthcare & Hospitals
    - Food & Beverage
    - Electronics Manufacturing
    - Laboratories & R&D
    - Medical & Surgical Devices
- **Styling:** Background images with hover overlay (`.hover-effect-1`).

### 5. Footer
- **Type:** Standard Global Footer (Dark Blue #004685, Light Blue #29afe3 accents, white text)

## Scripts
- **Owl Carousel:** For slider display.
