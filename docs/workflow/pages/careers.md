# Careers Page Design Documentation

**URL:** `/careers/`
**Source File:** `intoriza/careers/index.html`
**Parent Template:** N/A

## Page Overview
Lists current job openings and encourages potential candidates to join PakGusu Technology.

## Section-by-Section Design

### 1. Header
- **Type:** Standard Global Header
- **Includes:** Dark Mode Toggle. Header is always Dark Blue (#004685) with Light Blue (#29afe3) accents. See [Dark Mode](../dark-mode.md).

### 2. Page Title / Breadcrumb
- **Type:** Inner Page Banner (`.wt-bnr-inr`)
- **Content:** "Careers" title and breadcrumb.

### 3. Why Work With Us
- **Layout:** Text block or icon grid.
- **Content:** Company culture, benefits, growth opportunities.

### 4. Current Openings Section
- **Layout:** List or Accordion of job listings.
- **Content:**
    - Job Title
    - Department
    - Location
    - Brief Description
    - "Apply Now" or "View Details" link.
- **Styling:** Clean, scannable list format.

### 5. Application Form / Contact CTA
- **Layout:** Form or link to email/application portal.
- **Content:** Fields for Name, Email, Position Applied For, Resume Upload, Message.

### 6. Footer
- **Type:** Standard Global Footer (Dark Blue #004685, Light Blue #29afe3 accents, white text)
